| Exercício | O que pratica |
|---|---|
| hora-do-dia | Precisei aprender a utilização no "Date()" para a verificação e a obtenção de diversos elementos como: hora atual, minuto atual, segundos e o ano. |
| verificador-de-idade | Neste projeto aprendi a manipular melhor elementos HTML no JavaScriptcomo a criação de elementos (no caso deste projeto imagens) dentro do JS, também utilizei os conhecimentos obtidos no projeto anterior e como complemento modificar as especificidades/estilo dos tais no JS. |
| de-n-ate-n | Aqui coloquei em prática o conhecimento das estruturas de repetição para construir o projeto, com contagem progressiva e regressiva. |
| tabuada | Construção do clássico de tabuada, nele utilizei a estrutura de condição if/else e a estrutura de repetição for para conseguir multiplicar todos os números  necessários. |
| intervalos | Projeto mais desafiador e consequentemente o maior. Aqui foi onde aprendibastante e pratiquei muito dois conhecimentos fundamentais em qualquer linguagem de programação: Funções e Arrays. |

- *Observações Gerais:* Em todos os projetos utilizei a estrutura de repetição para validar as informações inseridas: Campo vazio, se é um número, se está dentro do intervalo...
